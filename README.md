# MUD

#Java Multi-User Dungeon (MUD) Project Description:

The Java Multi-User Dungeon (MUD) project is an object-oriented software application engineered to simulate an interactive text-based adventure game with a graphical user interface. 

- Object-Oriented Design (OOP): Built in Java, leveraging core OOP principles—such as classes, inheritance, encapsulation, and interfaces—to structure inventory systems, NPC movement, room navigation, and item interaction logic.

- Graphical User Interface (GUI): Features a custom desktop interface developed using Java Swing to present game states, room details, and user actions visually.

- Multithreading & Concurrency: Implemented multithreading using Java's ExecutorService to manage background tasks, real-time game loops, and concurrent entity behavior smoothly.

- Observer Design Pattern: Applied the Observer pattern to handle event-driven architecture, ensuring real-time UI state updates whenever player stats, room locations, or inventory items change.

- Software Practices: Incorporates robust exception handling, Java Collections Framework, and clean code practices to maintain performant, low-latency execution.
